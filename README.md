# Дипломный проект: Планировщик задач

Планировщик задач реализован для возможности планировать, отслеживать, повторять и закрывать задачи.

С помощью планировщика можно просматривать активные задачи, создавать новые задачи с комментариями, задавать правила повторения задачи.
Также возможен поиск задачи по тексту или дате.

## Выполненные задачи со звездочкой:

- Запуск сервера через переменную окружения 
- Возможность определять путь к файлу БД через переменную окружения
- Реализованы недельное правило повторение, а также по конкретному месяцу и дню 
- Поиск задачи по заданному тексту или дате

**Запланировано:**

- Реализовать аутентификацию  
- Реализовать Docker образ проекта 

## Инструкции по запуску кода локально:

- Изучите и скопируйте переменные из .env.example
- Запуск сервера из корня проекта командой `go run main.go`
- URL адрес localhost:7540 по умолчанию или, если вы подставили другой порт в переменную окружения, localhost:`ваш порт`

## Инструкции по запуску тестов

В файле tests/settings.go находятся актуальные настройки для тестов, изменять не нужно

## Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.
